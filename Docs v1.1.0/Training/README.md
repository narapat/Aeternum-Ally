## Refresh scope

Before publishing a v1.1.0 training deck:

1. Copy the reference deck to a new versioned file; do not overwrite the v1.0.0 source.
2. Update navigation and Start Here guidance against the current product.
3. Add current Settings, Integrations, role, and organization behavior.
4. Cover Tasks, Carbon, Evidence, and organization-owned Google Drive workflows.
5. Replace screenshots and verify every procedure against a current Deploy Preview or production release.
6. Compare terminology and workflows with [USER_MANUAL.md](../USER_MANUAL.md) and [FUNCTIONAL_SPEC.md](../FUNCTIONAL_SPEC.md).
7. Render the full deck, inspect every slide, and obtain product-owner review before customer delivery.
